# Miastenia gravis en Colombia

Sitio publicado del tablero sobre miastenia gravis en Colombia con datos de SISPRO (RIPS, MIPRES y RUAF). La app, los datos y los documentos están cifrados y se abren con contraseña.

Este repositorio solo contiene la versión publicada y cifrada. No lo edites a mano: lo genera el repositorio fuente (privado).
